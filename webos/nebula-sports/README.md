# Nebula Sports webOS

Thin webOS wrapper for Nebula Sports.

Build:

```bash
scripts/build-webos-ipk.sh
```

Install on TV with Developer Mode enabled:

```bash
ares-install --device <tv-name> dist/webos/com.nebulastreams.sports_1.0.11_all.ipk
```

Homebrew Channel custom repository:

```text
https://raw.githubusercontent.com/retrocodes12/NebulaSports/main/stable-v2.json
```
